# 🥗 Foodie-Health-Routine

> **“Eat Better. Live Better. Every Day.”**

A complete, modern, professional, responsive frontend food and wellness platform where users discover personalized daily food routines based on lifestyle, fitness goals, and metabolic health.

![Foodie-Health-Routine](https://images.unsplash.com/photo-1540420773420-3366772f4999?auto=format&fit=crop&w=1200&q=80)

---

## ✨ Features

- **🎨 Custom SVG Branding & Design System**:
  - Custom plate rim, vitality pulse, and emerald leaf logo concept.
  - Emerald Green, Fresh Mint, Warm Sun Amber, and crisp off-white color palette.
  - Google Fonts (*Plus Jakarta Sans* & *Outfit*), glassmorphism, micro-animations, and responsive cards.

- **🔍 Smart Search & Exploration Hub**:
  - Live debounced keyword search across routines, tags, ingredients, and dishes.
  - Quick category filters: *🩺 Health & Wellness*, *💪 Fitness*, *🔥 Weight Management*, *🥗 Vegetarian*, *🍗 High Protein*, *🎓 Student*, *⚡ Energy*, *🧘 Balanced Lifestyle*.
  - Dietary toggles (*100% Vegetarian*, *High-Protein*, *Low-GI*) and calorie range sliders.

- **🌅 Structured Daily Routine Timelines**:
  - 6 distinct daily slots: Morning Elixir, Breakfast, Afternoon Hydrator, Lunch, Evening Snack, Dinner.
  - Complete macronutrient counts (Calories, Protein, Carbohydrates, Fats, Fiber), prep time, and dietary tags.

- **📖 Interactive Recipe Modal & Direct Food Ordering**:
  - Interactive ingredient checklist with check-off states.
  - Step-by-step preparation guide with dietitian tips.
  - Curated YouTube resource cards for cooking walk-throughs.
  - External ordering shortcuts (**🛵 Order on Swiggy** & **🍴 Order on Zomato**).

- **🪄 "Create My Plan" 5-Step Wizard**:
  - Interactive questionnaire: Goal $\to$ Diet $\to$ Activity $\to$ Meal Frequency $\to$ Preferences.
  - Animated calculation screen with celebratory confetti and instant routine activation.

- **📊 "My Plan" & Daily Dashboard**:
  - Interactive meal completion checkboxes.
  - 7-day weekly planner schedule (Mon - Sun).
  - Water intake tracker (+250ml quick add with 8-glass visualizer).
  - Smart grocery shopping list with check-off items and one-click clipboard copy.
  - Full local storage synchronization across sessions.

- **👤 User Profile & Preferences**:
  - Habit streak tracker, saved routine library, and dietary preference editor.

---

## 🛠️ Tech Stack

- **Framework**: React.js 18 + Vite
- **Styling**: Vanilla CSS (Custom Design System with CSS Tokens, Glassmorphism & Micro-animations)
- **Icons**: Lucide React + Custom SVG Branding
- **Effects**: Canvas Confetti
- **State & Storage**: React Hooks (`useState`, `useMemo`, `useEffect`) + `localStorage` API

## 🚀 Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com/hb452431-prog/Foodie-health-routine.git
cd Foodie-health-routine
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Run Development Server
```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### 4. Build for Production
```bash
npm run build
```
